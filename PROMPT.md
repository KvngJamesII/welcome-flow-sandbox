# Reusable redesign prompt

Paste everything below the line, together with the repo link, to each AI:

---

Here is a repository containing the actual production signup and onboarding
code of my web app: <PASTE REPO LINK HERE>

Redesign the onboarding flow beautifully. This is one of our most important
pages: it must attract and welcome a new user, with not too much information
that confuses them.

Hard requirements:

- Every single element, font, color and piece of the onboarding page must be
  built carefully and nicely so it psychologically attracts new users.
- Keep the touch of the main site: the onboarding must not feel different
  from the rest of the site. Use the exact logo, brand colors and Plus
  Jakarta Sans font already in the code (the README lists the full brand
  system).
- Mobile-first: most visitors are on phones.
- Real icons (lucide-react), never emojis. Readable font sizes, nothing
  tiny. No decorative slogans or italics.
- Keep these flow elements in some form: Google sign-in, username/email/
  password signup, optional referral code, the 18+ / terms line, and the
  150 welcome credits idea for a new user's first booking code.

To see the current experience: `cd demo && npm install && npm run dev`, then
open `/signup`. The untouched production files are in `original-code/`.

Deliver your redesign as a pull request against this repo (fork it, push to
a branch, open a PR - you do not need any access token from me), or paste
the complete redesigned files back to me.

---
